Выберите необходимый формат для выгрузки готового файла

PEM .pem / .crt
PEM Сертификат

Текстовый формат с заголовками Base64. Стандарт для Nginx, Apache и Linux-серверов.

DER .der / .cer
Бинарный DER

Двоичный формат ASN.1 для Windows, Java KeyStore и криптографического оборудования.

PKCS#7 .p7b
PKCS#7 (P7B)

Контейнер сертификата и цепочки доверия CA без закрытого ключа для Windows и Java.

PKCS#12 .pfx / .p12
PKCS#12 (PFX)

Защищенный контейнер, включающий сертификат, закрытый ключ и цепочку (для Windows IIS / Tomcat).
